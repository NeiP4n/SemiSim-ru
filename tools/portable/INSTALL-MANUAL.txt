SEMISIM RUSSIAN TRANSLATION - JUST COPY THE FILES
================================================

WHAT IS IN THIS ARCHIVE
  ru-patch.jar        - the translation, 265 KB: 55 game classes with Russian
                        strings. Copy it NEXT TO SemiSim-2.2.1.jar.
  README.html         - Russian help page, replaces the file of the same name.
  examples.html       - Russian examples gallery, replaces the same-name file.
  install-translation.bat - Windows: copies everything and fixes the config.
                        Double-click it.
  install-translation.sh  - the same for Linux.

METHOD 1. Automatic (Windows)
  Close the game, then double-click install-translation.bat.
  If the game is not found, drag its folder onto this file.

METHOD 2. Automatic (Linux)
  chmod +x install-translation.sh
  ./install-translation.sh
  or with a path: ./install-translation.sh ~/.local/share/Steam/steamapps/common/SemiSim

METHOD 3. By hand, no scripts
  1. Copy ru-patch.jar into the game's lib/app folder.
  2. Open SemiSim.cfg in the same folder and insert ONE line at the very top
     of the app.classpath= list, before the first existing one:
         app.classpath=$APPDIR/ru-patch.jar
     The result should look like:
         [Application]
         app.classpath=$APPDIR/ru-patch.jar
         app.classpath=$APPDIR/SemiSim-2.2.1.jar
         app.mainclass=electrodynamics.SemiSim
         app.classpath=$APPDIR/archive-tmp/SemiSim-2.2.1.jar
  3. Copy README.html and examples.html into the same lib/app folder.
     Rename the originals to .orig before overwriting them.

WHY NO GAME FILE HAS TO BE REPLACED
  The JVM loads the first class it finds. The translation lives in ru-patch.jar,
  which is listed on the classpath before SemiSim-2.2.1.jar, so it overrides
  the original. The game's own JAR stays untouched, so Steam's integrity check
  passes and the English version is never restored.

GOING BACK TO ENGLISH
  Delete the ru-patch.jar line from SemiSim.cfg and delete ru-patch.jar.
  The help pages come back from their .orig copies.

DARK THEME
  Already in the game: File -> Settings -> UI theme -> FlatLaf Dark.
